# Gold Price Tracker (金価格自動トラッキング)

田中貴金属の金価格を毎日自動収集し、データとして蓄積するプロジェクトです。

## 概要
GitHub Actionsを用いて、PCをオフラインにしていても毎日自動で金価格をスクレイピングし、CSVファイルに記録します。資産運用やトレンド分析のためのデータ基盤として活用します。

## 主な機能
- **自動データ収集**: Pythonスクリプトによる田中貴金属サイトからの価格抽出。
- **自動実行**: GitHub Actionsによる毎日の定時実行。
- **データ蓄積**: 収集したデータを `gold_price.csv` に自動追記・保存。

## 使用技術
- Python
- BeautifulSoup (Webスクレイピング)
- GitHub Actions (自動実行環境)
